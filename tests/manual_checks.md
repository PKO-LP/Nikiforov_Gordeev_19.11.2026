# Сценарии ручной проверки

**Проект:** Учёт выдачи настольных игр «MyКубик». **Версия:** 1.0. **Авторы:** Никифоров, Гордеев, группа 11ТЭС-26.
**Дата проверки:** 19.11.2026. **Среда:** Windows, Python 3.13, Tkinter.

| Код теста | Требование | Действия пользователя | Ожидаемый результат | Фактический результат | Статус |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **AT-1** | FR-1 | Заполнить поля: игра «Каркассон», стол «3», гость «Алексей» и нажать «Добавить выдачу». | Запись с №1 и статусом «Выдана» появляется в таблице, форма очищается. | Запись №1 добавлена в таблицу со статусом «Выдана», поля формы очищены. | Пройден |
| **AT-2** | NFR-2 | Оставить поле «Название игры» пустым и нажать «Добавить выдачу». | Появляется предупреждение о незаполненных полях, запись не создаётся. | Показано окно предупреждения, список записей не изменился. | Пройден |
| **AT-3** | FR-2 | Кликнуть по строке записи в таблице. | Данные выбранной записи загружаются в верхние поля карточки. | Все поля записи и текущий статус отобразились в карточке. | Пройден |
| **AT-4** | FR-4 | Выбрать запись, изменить номер стола на «5» и нажать «Сохранить изменения». | Номер стола для выбранной записи обновляется в таблице. | Значение столбца «Стол» обновилось на «5». | Пройден |
| **AT-5** | FR-3 | Ввести в строку поиска «Карк» или выбрать фильтр статуса «Выдана». | В таблице отображаются только подходящие под условия записи. | Таблица отфильтровалась мгновенно, кнопка «Сбросить фильтры» возвращает весь список. | Пройден |
| **AT-6** | FR-5 | Попробовать перевести запись из «Выдана» сразу в «Возвращена», затем через «На проверке» → «Возвращена», затем повторить изменение финального статуса. | Прямой переход блокируется предупреждением; цепочка «Выдана» → «На проверке» → «Возвращена» работает; изменение финального статуса запрещено. | Все проверки правил перехода сработали корректно. | Пройден |
| **AT-7** | FR-6 | Выбрать запись, нажать «Удалить запись» и выбрать «Нет»; повторить и выбрать «Да». | При ответе «Нет» запись остаётся; при ответе «Да» запись удаляется из таблицы. | Запись сохранилась при отказе и удалилась после подтверждения. | Пройден |
| **AT-8** | NFR-1 | Закрыть окно приложения и запустить `src/main.py` повторно. | Приложение запускается менее чем за 2 секунды, список записей пуст. | Окно открылось мгновенно с пустой таблицей. | Пройден |
