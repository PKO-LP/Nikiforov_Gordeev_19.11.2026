# Учёт выдачи настольных игр «MyКубик»

Компания «MySoft» разрабатывает небольшие приложения для автоматизации повседневных задач бизнеса. К нам обратился заказчик «MyКубик» — клуб-антикафе настольных игр. Администраторы клуба сталкиваются с проблемой: учёт выданных игр ведётся на бумажных бланках, из-за чего сотрудники путаются в занятых коробках, забывают проверять комплектацию при возврате и тратят много времени на поиск свободных экземпляров. Нам поручили разработать настольное приложение для учёта выдачи настольных игр, чтобы ускорить обслуживание гостей и исключить потерю комплектов.

**Авторы:** Никифоров, Гордеев, группа 11ТЭС-26. **Срок:** 3 спринта по 2 недели (всего 6 недель). **Статус:** Завершён, выпуск v1.0.


## Заказчик и проблема

«MyКубик» — городской клуб настольных игр, где посетители берут коробки с играми за игровые столы на время посещения. Сейчас администраторы записывают выдачу от руки в тетрадь, поэтому при высокой загрузке сложно быстро понять, какая игра у какого стола находится и в каком состоянии её вернули.

## Планируемая функциональность

В первую версию приложения включены 6 основных функций:

- Добавление записи о выдаче игры (название игры, номер стола, имя гостя, время выдачи, состояние комплекта при выдаче).
- Просмотр общего списка выданных игр и подробной карточки выбранной записи.
- Изменение данных записи с проверкой заполнения обязательных полей.
- Поиск записи по названию игры или имени гостя и фильтрация списка по статусу.
- Изменение статуса по правилам: «Выдана» → «На проверке» → «Возвращена» (или «Требует ремонта»).
- Удаление выбранной записи с обязательным подтверждением пользователя.

## Установка и запуск

1. Скачайте папку проекта на компьютер и откройте её в терминале или редакторе VS Code.
2. Убедитесь, что установлен Python 3.11 или новее с поддержкой стандартной библиотеки Tkinter (проверено на Python 3.13).
3. Внешние библиотеки для базовой версии не требуются.
4. После создания главного файла программы выполните запуск командой:

```bash
python src/main.py
```

**Примеры записей для демонстрации:**
- Игра: `Каркассон`, Стол: `3`, Гость: `Алексей`, Время: `14:15`, Состояние: `Полный комплект`, Статус: `Выдана`.
- Игра: `Колонизаторы`, Стол: `7`, Гость: `Марина`, Время: `15:00`, Состояние: `Помята коробка`, Статус: `На проверке`.
- Игра: `Бункер`, Стол: `1`, Гость: `Дмитрий`, Время: `16:30`, Состояние: `Полный комплект`, Статус: `Возвращена`.

## Технологический стек

- **Язык программирования:** Python 3.13.
- **Графический интерфейс:** Tkinter (окна, поля ввода, кнопки, таблица/список записей).
- **Хранение данных:** список словарей Python в оперативной памяти во время работы программы. База данных и SQL не требуются; после закрытия окна записи сбрасываются.

## Спринты разработки

1. **Спринт 1 — первая рабочая версия.** Выбор темы, заполнение устава, требований, плана и ТЗ. Создание окна Tkinter с вводом и добавлением записей о выдаче игр в список. **Результат:** можно добавить запись и увидеть её на экране.
2. **Спринт 2 — основные сценарии.** Добавление поиска по игре и гостю, фильтрации по статусу, редактирования записи и смены статуса по правилам. Уточнение документации. **Результат:** можно найти запись, изменить её данные и статус.
3. **Спринт 3 — готовый продукт.** Добавление удаления записи с подтверждением, ручное тестирование всех сценариев, исправление ошибок, добавление скриншотов и финализация документации. **Результат:** все согласованные функции работают, подготовлен выпуск v1.0.
