# Документация продукта

**Продукт:** Учёт выдачи настольных игр «MyКубик». **Версия:** 1.0. **Авторы:** Никифоров, Гордеев, группа 11ТЭС-26.
**Дата:** 19.11.2026.

## Назначение и возможности

Настольное приложение «MyКубик» предназначено для администраторов клуба настольных игр и автоматизирует учёт выдачи коробок с играми за игровые столы. Программа позволяет оформлять выдачу, отслеживать занятые столы, проверять состояние комплектации при возврате, искать записи по игре или гостю и контролировать статус каждой выдачи.

## Требования и запуск

- Операционная система: Windows 10 / 11 (также поддерживаются Linux и macOS с установленным пакетом `python3-tk`).
- Среда выполнения: Python 3.11 или новее (проверено на Python 3.13) со стандартной библиотекой Tkinter. Установка внешних библиотек из `requirements.txt` не требуется.
- Запуск приложения из папки проекта:

```bash
python src/main.py
```

## Основные сценарии работы

1. **Добавление выдачи игры.** Заполните обязательные поля в верхнем блоке «Карточка выдачи игры» (название игры, номер стола, имя гостя), при необходимости уточните время и состояние комплекта, затем нажмите **«Добавить выдачу»**. Новая запись появится в нижней таблице со статусом «Выдана».
2. **Просмотр и редактирование записи.** Нажмите левой кнопкой мыши на нужную строку в таблице — её данные заполнят верхнюю карточку. Измените нужные поля и нажмите **«Сохранить изменения»**. Чтобы выйти из режима редактирования без сохранения, нажмите **«Очистить форму»**.
3. **Смена статуса выдачи.** Выберите строку в таблице и используйте кнопки блока «Управление статусом выбранной записи»:
   - **«Отправить на проверку»** — переводит игру из статуса «Выдана» в «На проверке» после возврата коробки со стола.
   - **«Принять (Возвращена)»** — переводит проверенную игру из статуса «На проверке» в «Возвращена».
   - **«В ремонт (Требует ремонта)»** — переводит игру с повреждёнными компонентами из статуса «На проверке» в «Требует ремонта».
4. **Поиск и фильтрация.** Введите часть названия игры или имени гостя в поле «Поиск» либо выберите нужный статус в выпадающем списке. Для возврата ко всему списку нажмите **«Сбросить фильтры»**.
5. **Удаление записи.** Выберите строку в таблице, нажмите **«Удалить запись»** и подтвердите действие в диалоговом окне кнопкой **«Да»**.

## Важные особенности и ограничения

- **Хранение в памяти.** Все записи хранятся в списке словарей в оперативной памяти только во время открытого окна программы. После закрытия приложения список очищается, база данных не используется.
- **Контроль ввода.** Если оставить пустым название игры, номер стола или имя гостя, программа выведет предупреждение и не сохранит неполную запись.
- **Строгий порядок статусов.** Перепрыгнуть этап проверки или изменить финальный статус («Возвращена», «Требует ремонта») нельзя — система предупредит о нарушении правила.
